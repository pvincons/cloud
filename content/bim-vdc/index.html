Chức năng & Chỉ dẫn quản trị

Quản lý Cây thư mục Central: Kiểm tra thư mục dự án, dung lượng file Central và lịch sử đồng bộ (Synchronize history) các bộ môn Kiến trúc, Kết cấu, MEP.

Xử lý Lock/Unlock: Hỗ trợ Admin mở khóa hoặc đóng băng file Central khi phát sinh xung đột đồng bộ giữa nhiều kỹ sư làm việc từ xa.

Quy trình kết nối cho Kỹ sư

  1. Khởi chạy VPN Tailscale hoặc kết nối mạng nội bộ công ty.
  2. Mở Autodesk Revit 2027 > Chọn Open Project > Chọn tab Revit Server.
  3. Nhập Accelerator / Server revit.pvincons.cloud để tạo file Local.
